# Personal Portfolio Website

A simple personal portfolio website created using **HTML and CSS**. The website provides a clean and easy-to-navigate interface to introduce myself and provide my contact information.

## 📄 Pages

- **Home** – Contains my introduction, basic information, and portfolio content.
- **Contact** – Provides my contact details and a way for visitors to get in touch with me.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure and content of the website.
- **CSS3** – Used for styling, layout, fonts, colors, and overall appearance.

## 🎯 Project Purpose

This project was created to practice my **HTML and CSS skills** and build a simple personal portfolio website that can be used to showcase my profile online.

## ✨ Features

- Simple and clean design
- Easy navigation between Home and Contact pages
- Beginner-friendly HTML and CSS implementation
- Responsive layout
